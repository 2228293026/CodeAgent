# CodeAgent 项目介绍

> 一个用 C#（.NET 10）编写的 **LLM 驱动编码助手 CLI**，像 Claude Code / Aider 一样，在终端里自主理解任务、读写代码、执行命令，直到把活干完。

## 这是什么

CodeAgent 是一个跑在命令行里的 AI 编程搭档。你用自然语言描述任务（例如「给 ToolRegistry 加一个单元测试」「解释一下这个项目怎么构建」），它会：

1. 调用大模型进行推理；
2. 自主决定调用哪些工具（读文件、搜代码、改代码、跑命令）；
3. 把工具结果回填给模型，继续推理，循环往复；
4. 直到任务完成，给出最终答复。

它同时支持 **OpenAI 兼容协议**（OpenAI / DeepSeek / 通义千问 / Ollama / Moonshot / 智谱 等）与 **Anthropic Claude**，通过配置文件随时切换，无需改代码。

## 核心能力

- **自主 Agent 循环**：模型调用工具 → 结果回填 → 继续推理，直到给出最终答复。
- **流式输出**：回复逐字打印，接近真实对话体验。
- **并行工具调用**：同一轮多个工具并发执行，写操作自动退化为顺序。
- **上下文自动摘要**：历史超限时先用 LLM 压缩，失败才回退丢弃旧消息。
- **多工作模式**：`code` / `plan` / `explain` / `review` 等，只读模式自动拦截写工具。
- **内置 10 个工具**：`read_file` / `write_file` / `edit_file` / `list_directory` / `glob` / `grep` / `run_command` / `bash` / `powershell` / `stop`。
- **工作区沙箱**：文件工具无法访问工作区之外；命令执行可选逐个确认。
- **会话日志与撤销**：每轮对话写入 `.codeagent/sessions/*.jsonl`，支持 `/undo` 撤销、`/diff` 审查改动。

## 适用场景

- 在已有代码库里做局部修改、补测试、查 bug、写文档；
- 作为 CI / 脚本里的一次性编码助手（`codeagent "任务"`）；
- 日常交互式结对编程（REPL 模式，带命令历史、TAB 补全、行内编辑）。

## 快速上手

需要 [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)。

```bash
# 构建
dotnet build -c Release

# 交互式配置供应商（推荐）
dotnet run --project src/CodeAgent -- --setup

# 运行一次任务
dotnet run --project src/CodeAgent -- "帮我看下这个项目的结构，并写一个 README"
```

更完整的配置、命令、REPL 用法与安全说明，请见根目录的 **[README.md](./README.md)**。
