# 工具参考

CodeAgent 内置 10 个工具，由 Agent 自主调用。所有文件工具受工作区沙箱约束（见 [配置参考.md](./配置参考.md) 的 `fileAccess` / `readOnlyDirs`）。

## 文件工具

### read_file
带行号读取文件内容。
- `path`（必填）：文件路径（相对工作区或绝对路径）。
- `offset`（可选）：起始行号（1 起）。
- `limit`（可选）：最多读取行数（默认 300，最大 5000）。
- `tail`（可选）：读取末尾 N 行（1-5000，日志排查用；与 `offset` 同时给出时优先）。
- `no_line_numbers`（可选）：不带行号输出原文。
- 二进制文件与目录会给出明确提示，不会输出乱码。

### write_file
创建或覆盖文件。
- `path`（必填）：目标文件路径。
- `content`（必填）：完整文件内容；**缺 `content` 会报错而非写空文件**。
- `create_dirs`（可选）：自动创建父目录（默认 true）。
- 整体覆盖已有文件（覆盖前会记录撤销快照，供 `/undo` 恢复）；内容与现状相同则跳过写入。

### edit_file
精确文本替换（类似补丁）。
- `path`（必填）：文件路径。
- `old_string`（必填）：要替换的原文（逐字匹配，含缩进与空白）。
- `new_string`（必填）：替换后的文本。
- `replace_all`（可选）：出现多次时是否全部替换；默认 `false`，重复匹配会报错。
- 换行风格容错：`old_string` 用 LF 而文件是 CRLF（或反过来）时自动归一化匹配，替换片段跟随文件的换行风格。
- 撤销可精确恢复；`/diff` 可显示最近一次修改的 diff 预览。

### list_directory
列出目录树，跳过构建/缓存目录（如 `bin/`、`obj/`、`.git/`）。
- `path`（可选）：目录路径，默认工作区根。
- `depth`（可选）：递归深度（默认 2，最大 5）。
- 输出末尾附统计摘要（N 个目录、M 个文件）；条目超过 800 时截断并提示。

## 搜索工具

### glob
按 glob 模式查找文件。
- `pattern`（必填）：可用字符串或数组；支持 `*`、`?`、`**` 跨目录、字符类 `[ab]` / `[a-z]` / `[!abc]` 与花括号多选 `{a,b}`。
- `path`（可选）：搜索起点目录，默认工作区根。
- 示例：`src/**/*.cs`、`**/*.md`。

### grep
正则搜索文件内容。
- `pattern`（必填）：正则表达式（智能大小写：全小写忽略大小写，含大写精确匹配）。
- `path`（可选）：搜索起点目录。
- `include` / `exclude`（可选）：glob 限定文件范围，如 `"*.cs"`。
- `context`（可选）：上下文行数（默认 3，最大 10）。
- `max_results`（可选）：最大结果数（默认 50，最大 500）；达到上限时输出会附「可能还有更多匹配」提示。
- `files_only`（可选）：只返回匹配的文件路径。
- `case_sensitive`（可选）：强制区分大小写（覆盖智能大小写）。
- `multiline`（可选）：跨行匹配——`\n` 视为普通字符参与匹配（适合多行块如 JSON/HTML 片段）；长命中折叠显示前几行并标注行号范围。

## 命令工具

> 受 `allowCommands` / `confirmCommands` 控制；`confirmCommands: true` 时每个命令执行前逐个确认。

### run_command
执行 shell 命令（构建/测试/git 等），带超时。
- 实际使用的 shell 由配置 `shell` 决定（留空自动检测：Windows 优先 Git Bash，其次 powershell）；会话内可用 `/shell` 运行时切换。
- `command`（必填）：要执行的命令。
- `timeout_seconds`（可选）：超时秒数（默认取配置，最大 300）。
- `cwd`（可选）：执行目录（相对工作区）。
- `env`（可选）：附加环境变量（字符串键值对）。

### bash
在 bash（Git Bash）中执行命令，支持管道、环境变量与 Unix 工具链。
- `command`（必填）、`timeout_seconds`（可选）、`cwd`（可选）、`env`（可选）。

### powershell
在 PowerShell（优先 pwsh 7，否则 Windows PowerShell 5.1）中执行命令，支持管道与对象。
- `command`（必填）、`timeout_seconds`（可选）、`cwd`（可选）、`env`（可选）。

## 会话工具

### stop
模型完成任务后调用，结束本轮对话。
- 无参数（可附 `reason` 说明结束原因）。

## 沙箱与权限

- `strict`（默认）：文件读写都限制在工作区内，无法访问工作区之外。
- `whitelist`：工作区 + `readOnlyDirs` 只读白名单；读/搜索工具可访问白名单目录，但写工具与命令执行仍限工作区。
- `full`：完全放开沙箱，所有文件可读可写（仅用于信任场景；切换时会二次确认）。

切换方式（无需重启，写回配置持久化）：`/access next`、`/access whitelist`，或 REPL 内 `Shift+Tab` 循环切换。
