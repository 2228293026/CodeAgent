# 配置参考

CodeAgent 的所有行为都由一个 JSON 配置文件驱动，无需改代码即可切换供应商、模型、权限与界面行为。

## 配置查找顺序

程序启动时按以下优先级加载配置（后者被前者覆盖，仅覆盖 JSON 中出现的字段，其余保留默认）：

1. `-c` / `--config` 显式指定的路径；
2. 当前工作目录下的 `codeagent.json`；
3. 用户主目录下的 `~/.codeagent/config.json`（全局配置）；
4. 以上都不存在时，使用内置默认值。

> 反序列化容错：JSON 支持注释（`//`）、尾随逗号；中文原样保留（不转义为 `\uXXXX`）。非法数值会被收敛到安全范围（`maxToolIterations` 限 0–200，`maxHistoryChars` 限 1000–20,000,000），避免误配导致空转或 OOM。

## 生成与编辑

```bash
dotnet run --project src/CodeAgent -- --init    # 生成完整示例 codeagent.json 到当前目录
dotnet run --project src/CodeAgent -- --setup   # 交互式向导：选供应商、填模型，自动生成
```

## 顶层字段

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `provider` | string | `"openai"` | 当前使用的 Provider 名称，对应 `providers` 字典的键 |
| `providers` | object | 见下 | 各供应商连接与模型选项（字典，键为名称） |
| `maxToolIterations` | int | `0` | 单轮任务最大工具调用轮数；`0` 或负数 = 不限制（无限） |
| `maxHistoryChars` | int | `160000` | 历史消息总字符上限，超出后从最旧处裁剪/摘要 |
| `contextWindow` | int | `0` | 模型上下文窗口（token）：状态栏 ctx 百分比用；`0` = 自动识别（内置模型表 + `/models` 元数据探测），识别不到显示绝对值 |
| `pricePerMillionInput` | double | `0` | 输入单价（$/百万 token）；>0 时回合摘要与 `/stats` 显示费用估算 |
| `pricePerMillionOutput` | double | `0` | 输出单价（$/百万 token） |
| `commandTimeoutSeconds` | int | `60` | 命令默认超时秒数（模型可按调用覆盖，上限 300，钳制 1-300） |
| `allowCommands` | bool | `true` | 是否允许 `run_command` / `bash` / `powershell` 执行命令 |
| `confirmCommands` | bool | `false` | 执行命令前是否逐个询问确认 |
| `shell` | string | `""` | 命令使用的 shell：`cmd` \| `powershell` \| `bash`；留空自动（Windows 用 cmd） |
| `saveSessions` | bool | `true` | 是否把每轮对话写入会话日志 |
| `sessionDir` | string | `".codeagent/sessions"` | 会话日志目录（相对工作目录） |
| `exportDir` | string | `".codeagent/exports"` | `/export` 导出 Markdown 的目标目录（相对工作目录） |
| `streamOutput` | bool | `true` | 流式输出模型回复（逐字打印） |
| `showToolCalls` | bool | `true` | 终端实时显示工具调用过程（动作、耗时、输出预览） |
| `renderMarkdown` | bool | `true` | 对模型回复做 Markdown 渲染（代码块/行内代码/加粗/标题着色） |
| `tuiAnsi` | bool | `true` | 用 ANSI 转义做菜单原地渲染；老式终端乱码时设 `false` 退回滚动式 |
| `thinkingEffort` | string | `"off"` | 模型思考强度：`off`（关闭）\| `auto`（自动探测模型支持的档位并取最高可用——先查 /models 元数据 reasoning.effort 字段，查不到用内置模型名前缀表判断；供应商声明支持 high 就用 high，只支持 low 就用 low，不支持/无法判断则不发送）\| `low` / `medium` / `high`（仅对支持推理参数的模型生效） |
| `defaultMode` | string | `"code"` | 启动时的默认工作模式（`/mode` 可切换） |
| `fileAccess` | string | `"strict"` | 文件访问权限：`strict` \| `whitelist` \| `full` |
| `readOnlyDirs` | string[] | `[]` | 只读白名单目录（`whitelist` 模式生效） |
| `modes` | array | `[]` | 自定义工作模式列表 |
| `systemPrompt` | string | 内置默认 | 自定义系统提示；留空用内置默认（ADOFAI 适配等注入依赖此项为空） |

## providers 子项（ProviderOptions）

`providers` 是一个以名称为键的字典，每个值包含以下字段：

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `type` | string | `"openai"` | Provider 类型：`openai`（OpenAI 兼容协议）\| `anthropic` |
| `baseUrl` | string | `""` | API 基础地址；留空用内置默认 |
| `model` | string | `""` | 模型名；留空用内置默认 |
| `apiKeyEnv` | string? | `null` | 存放 API Key 的环境变量名 |
| `apiKey` | string? | `null` | 直接写 API Key（不推荐，优先于 `apiKeyEnv`）；仅测试用 |
| `maxTokens` | int | `8192` | 单次回复最大 token 数 |
| `temperature` | double | `0.2` | 采样温度 |

> `type: "openai"` 表示「OpenAI 兼容协议」，DeepSeek、通义、Ollama、Moonshot、智谱等都走这个类型，只需换 `baseUrl` 和 `model`。若模型不支持 function calling / tool use，Agent 将无法工作。

## modes 子项（AgentModeConfig）

自定义工作模式，结构如下：

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `name` | string | `""` | 模式名（`/mode <name>` 切换） |
| `description` | string | `""` | 模式描述（`/mode` 列表展示） |
| `systemPrompt` | string | 内置默认 | 该模式的系统提示 |
| `tools` | string[]? | `null` | 可用工具名列表；空/省略 = 全部工具 |

详见 [工作模式.md](./工作模式.md)。

## 安全提示

- API Key 建议通过环境变量注入，避免写进配置仓库；`codeagent.json` 若入库请先加入 `.gitignore`。
- 会话日志（`.codeagent/`）可能包含代码内容，注意勿提交到公共仓库。
- 不信任模型给出的命令时，设 `"confirmCommands": true` 逐个确认，或 `"allowCommands": false` 完全禁用命令执行。
