# 常见问题

## 菜单乱码 / 界面错位

斜杠命令菜单使用 ANSI 转义序列原地渲染，需要支持 VT 的终端（Windows Terminal、VS Code 终端、新版 conhost）。老式终端或重定向输出出现乱码时，在 `codeagent.json` 设 `"tuiAnsi": false` 退回滚动式菜单。

## 回复说到一半就断了

输出达到 `maxTokens` 上限时被截断（状态会显示 `⚠ 输出被 max_tokens 截断`）。在 `codeagent.json` 对应 provider 里调大 `maxTokens`（如 16384）即可。

## 报「模型未返回内容」

常见于免费代理模型的限额/速率限制。可用 `/retry` 重试、`/models` 换模型，或等一会儿。429 / 5xx / 网络错误会自动重试 2 次（指数退避）。

## 上下文快满了（ctx 百分比高）

- `/compact [重点]` 主动把最早的对话压缩成摘要（压缩中显示进度，ESC 可取消；可附保留重点，如 `/compact 保留接口设计`，会并入摘要指令）；
- 状态栏 ctx 达到 90% 时，回合结束会提示建议压缩；
- `maxHistoryChars`（默认 160k 字符）超限时自动裁剪：先截短工具结果 → LLM 压缩 → 丢弃最早的对话块；
- ESC 多级撤回也可以回退掉跑偏的轮次（注意：不可越过历史压缩点）。

## 怎么接本地 Ollama

`--setup` 向导选 Ollama（自动填 `http://localhost:11434/v1`，无需 Key），或手动：

```json
"provider": "ollama",
"providers": { "ollama": { "type": "openai", "baseUrl": "http://localhost:11434/v1", "model": "qwen2.5-coder:7b", "apiKey": "ollama" } }
```

## 老 Windows 项目的中文文件会乱码吗

不会。读文件（read_file / grep 等）与命令输出（cmd/dotnet 等）都自动识别编码：BOM 优先，无 BOM 时先按严格 UTF-8 校验，失败则回退 GB18030（覆盖 GBK/ANSI）。写回时保持文件原编码——GBK 文件改完仍是 GBK、带 BOM 的 UTF-8 保留 BOM，不会被动转换；依赖 BOM 或 ANSI 编码的工具（如 PowerShell 5.1、旧编译脚本）不受影响。

## API Key 安全

- 推荐环境变量方式（`apiKeyEnv`），Key 不落盘；
- `codeagent.json` 已在 .gitignore 中，**不要**把含 `apiKey` 的配置提交进仓库；
- 全局配置放 `~/.codeagent/config.json`，按项目可用 `provider` 字段切换。

## 会话怎么恢复

每条消息自动写入 `.codeagent/sessions/*.jsonl`（`saveSessions` 控制）。`codeagent --continue` 恢复最近一次；会话内 `/resume` 列出最近 10 次按编号恢复。启动后没对话就退出的空日志会被自动跳过。

## 命令执行被拒绝

依次检查：`allowCommands` 是否为 true；`fileAccess` 是否为 strict（命令的工作目录仍限工作区）；`confirmCommands` 开启时每个命令需输入 `y` 确认（终端焦点要在窗口上）。

## 工具修改了文件想回退

`/undo`（Alt+U）撤销最近一次文件修改，`/undo N` 撤 N 步，`/undo list` 看栈；`/diff`（Alt+D）看改动内容。命令产生的文件副作用同样入撤销栈。

## powershell 工具报「pwsh: not found」

`powershell` 工具在 Linux/macOS 上需要安装 PowerShell 7（`pwsh`）。Windows 无需安装——自动使用系统自带的 Windows PowerShell 5.1。只用 `bash` / `run_command` 的话可以忽略。

## 命令取消后 CPU 还在跑？

ESC/Ctrl+C 取消回合时会同步终止正在运行的命令进程树（包括 `dotnet build` 的子进程）。若在旧版本（0.2.0 之前）观察到取消后进程残留，升级即可。

## 中文会话的 token 估算准吗

无 usage 返回时的回退估算按「ASCII 4 字符/token、中日韩每字 1 token」计算（emoji 等代理对按 1 个码点计）；配置了 `contextWindow` 或服务返回 usage 时以真实值为准（状态栏 ctx 即真实 prompt_tokens）。

## 启动时提示「未知配置项」

`codeagent.json` 里有拼写错误或已废弃的字段。加载器会忽略未知键，所以该配置从未生效过——对照[配置参考](./配置参考.md)修正名称即可。provider 内部与自定义模式里的未知键也会同样报告；非法枚举值（如 `thinkingEffort: "ultra"`）会提示已回退默认值。

## /compact 的摘要在 Claude 上丢了？

没丢。摘要以「对话中间的 system 消息」插入，而 Anthropic 没有中途 system 角色——现在会自动转成 user 文本块随请求发送，Claude 能正常读到压缩后的上下文。

## ADOFAI 项目里 codeagent.json 被写入了大段注入文本？

旧版本的缺陷：运行时注入的开发上下文会随 `/model`、`/thinking` 等保存操作被持久化进用户配置。现已改为仅会话内生效、不落盘。旧配置如已被写入过一次，手动删除 `systemPrompt` 里的注入段落即可（保留你自己写的部分）。

## CODEAGENT_PROVIDER 环境变量变成了配置文件的默认 provider？

同上，属会话级覆盖被意外持久化的缺陷，已修复：环境变量 / `-p` 的覆盖只在本次运行生效；`/provider` 显式切换才会写入配置文件。

## 怎么找之前某段对话

`/find <关键字>` 在历史会话日志里搜索（最新在前，显示命中片段与时间），找到后用 `/resume <编号>` 恢复该会话继续聊。斜杠命令行不算命中内容。
