# 常见问题

## 菜单乱码 / 界面错位

斜杠命令菜单使用 ANSI 转义序列原地渲染，需要支持 VT 的终端（Windows Terminal、VS Code 终端、新版 conhost）。老式终端或重定向输出出现乱码时，在 `codeagent.json` 设 `"tuiAnsi": false` 退回滚动式菜单。

## 报「模型未返回内容」

常见于免费代理模型的限额/速率限制。可用 `/retry` 重试、`/models` 换模型，或等一会儿。429 / 5xx / 网络错误会自动重试 2 次（指数退避）。

## 上下文快满了（ctx 百分比高）

- `/compact` 主动把最早的对话压缩成摘要；
- `maxHistoryChars`（默认 160k 字符）超限时自动裁剪：先截短工具结果 → LLM 压缩 → 丢弃最早的对话块；
- ESC 多级撤回也可以回退掉跑偏的轮次（注意：不可越过历史压缩点）。

## 怎么接本地 Ollama

`--setup` 向导选 Ollama（自动填 `http://localhost:11434/v1`，无需 Key），或手动：

```json
"provider": "ollama",
"providers": { "ollama": { "type": "openai", "baseUrl": "http://localhost:11434/v1", "model": "qwen2.5-coder:7b", "apiKey": "ollama" } }
```

## API Key 安全

- 推荐环境变量方式（`apiKeyEnv`），Key 不落盘；
- `codeagent.json` 已在 .gitignore 中，**不要**把含 `apiKey` 的配置提交进仓库；
- 全局配置放 `~/.codeagent/config.json`，按项目可用 `provider` 字段切换。

## 会话怎么恢复

每条消息自动写入 `.codeagent/sessions/*.jsonl`（`saveSessions` 控制）。`codeagent --continue` 恢复最近一次；会话内 `/resume` 列出最近 10 次按编号恢复。启动后没对话就退出的空日志会被自动跳过。

## 命令执行被拒绝

依次检查：`allowCommands` 是否为 true；`fileAccess` 是否为 strict（命令的工作目录仍限工作区）；`confirmCommands` 开启时每个命令需输入 `y` 确认（终端焦点要在窗口上）。

## 工具修改了文件想回退

`/undo`（Alt+U）撤销最近一次文件修改，`/undo N` 撤 N 步，`/undo list` 看栈；`/diff`（Alt+D）看改动内容。命令产生的文件副作用同样入撤销栈。
