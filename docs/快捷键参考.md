# 快捷键参考

所有快捷键都在**交互模式**的输入行生效；`stdin` 被重定向（管道/脚本）时自动回退为逐行读取，快捷键不可用。

## 输入编辑

| 按键 | 作用 |
|------|------|
| `←` / `→` | 行内移动光标（多行输入时跨行） |
| `↑` / `↓` | 多行输入时行间移动（折叠状态下先展开再移动）；单行时浏览命令历史（持久化在 `.codeagent/history.txt`，最多 100 条，重复命令只保留最新位置） |
| `Home` / `End` | 当前行的行首 / 行尾（多行输入时按行移动；Ctrl+Home 等全局跳转未绑定，`/history` 可回看全文） |
| `Backspace` / `Delete` | 删除光标前 / 后的字符（emoji 等代理对整体删除，不会劈成半个乱码） |
| `Ctrl+←` / `Ctrl+→` | 按单词移动光标（跳过空白再跳一个词） |
| `Ctrl+Backspace` / `Ctrl+Delete` | 删除光标前 / 后的一个单词（含相邻空白） |
| `Enter` | 提交输入；粘贴流中的换行会作为多行内容插入而不提交（支持终端括号粘贴标记，判定确定性；不支持的终端回退按键间隔启发式） |
| `Shift+Enter` | 手动插入换行（多行输入；无需粘贴） |
| `Ctrl+L` | 清屏（菜单打开时自动重绘菜单） |
| `Ctrl+C` | 回合运行中：优雅取消本轮；空闲时：退出程序 |
| `Ctrl+Z` / `Ctrl+D` | EOF 退出 |

## 斜杠命令菜单（输入 `/` 自动弹出）

| 按键 | 作用 |
|------|------|
| 继续输入 | 前缀过滤（兼容中文输入法的全角 `／`） |
| `↑` / `↓` | 移动选中项（超过 9 项时窗口自动滚动） |
| `→` | **把选中命令填入输入行**（不执行，可继续加参数）；无选中时填第一项 |
| `Tab` | 多个匹配时循环换选；唯一匹配时补全并关闭菜单 |
| `1`-`9` | 直接执行可见窗口内的第 N 项（完整命令名已输入时数字视为参数） |
| `Enter` | 执行选中项；未选中时提交当前输入 |
| `Esc` | 关闭菜单 |
| `Shift+Tab` | 菜单内反向循环选择项 |

菜单是**固定高度稳定面板**（表头 + 9 项 + more 行）：开/关时输入行各移动一次，过滤与选择全部原地重绘。

## 模式与权限

| 按键 | 作用 |
|------|------|
| `Tab`（非 `/` 开头时） | 切换下一个工作模式（`/mode next`） |
| `Shift+Tab`（菜单外） | 循环切换文件访问权限 strict → whitelist → full（`/access next`） |
| `Alt+M` / `Ctrl+Shift+M` | 模式选择菜单（数字键不拦截，避免误切） |
| `Alt+U` / `Ctrl+Shift+U` | 撤销最近一次文件修改（`/undo`） |
| `Alt+D` / `Ctrl+Shift+D` | 查看最近修改的 diff（`/diff`） |
| `Alt+N` / `Ctrl+Shift+N` | 新建会话（`/clear`） |

部分终端会吞 `Alt` 组合键，因此每个快捷键都提供 `Ctrl+Shift` 兜底。

## 回合运行中

| 按键 | 作用 |
|------|------|
| `Esc` | 取消当前回合（停止模型思考/工具执行），历史自动回滚为合法状态，输入回填草稿 |
| `Ctrl+C` | 同上（取消后空闲再按才退出） |

运行期间的其他按键会被取消监视线程吞掉（typeahead），这是刻意的：防止误触。

## 会话撤回（Esc）

| 按键 | 作用 |
|------|------|
| `Esc`（空输入第一次按） | 输入行显示「再按 Esc 撤回上一条消息」确认提示；按其他键则取消并继续编辑 |
| `Esc`（空输入，确认后再按） | 撤回最近一轮对话；**连按可逐轮回退**（多级撤回），不可越过历史压缩点 |

## 反向搜索历史（Ctrl+R）

| 按键 | 作用 |
|------|------|
| `Ctrl+R` | 进入搜索模式；再按跳到更早的下一个命中 |
| 继续输入 | 追加到搜索词，输入行跳到最新命中（忽略大小写） |
| `Backspace` | 删搜索词末字符并重新命中 |
| `Enter` | 提交当前命中的历史条目 |
| `Esc` | 退出搜索，保留命中文本继续编辑 |
| `↑` / `↓` | 退出搜索，回到普通历史浏览 |

输入行会显示 `(搜索)\`搜索词\` 命中文本`。
